# Opt-in Mono 6.6 / ordinary MCP qualification

These fixtures are independently authored. The four embedded PNGs are the exact
opaque 101–104 procedural images used in the actual ORT worker gate: red car,
green tree, red apple and yellow banana. Asset names are deliberately not semantic
labels. Same-color red car/red apple retrieval checks content, not a color ranking.

Root first promotes the actual production candidate, merges per-action scheduler
policies, updates the Test embedded package, and installs only this fixture `.cs`
under a fresh owned Test `Assets/Editor` directory with nonoverwriting SHA journal.
Wait for actual Editor import/compile readiness and fresh MCP tools/schema hash.
Do not launch another Editor from this runner. All qualification launches require
an administrator token. Deferred Unity 7/CoreCLR and the canceled Mono crash
investigation are not part of this gate.

The native fixture creates a uniquely named Assets folder and imports its four
own PNGs synchronously. It records bytes/SHA for every own PNG and .meta and exact
open/active scene handles, paths and dirty states. It never saves or reloads a
scene or selects a user object. Cleanup refuses changed, unknown or reparse content.
An existing disposable visual index is backed up and restored only against a
known-write hash journal; new foreign index entries are preserved/rejected.
Global user model files are never unset/renamed. The unready test hides only the
exact SHA-qualified newly installed Test embedded companion binary, then restores
it byte-identically. A project-cache resolution is rejected before hiding.

The wire gate initializes protocol 2025-11-25, validates every production result's
actual raw `structuredContent` using independent JSON Schema 2020-12, and checks
the reserved text delivery mirror separately. Expected negatives must really
produce MCP `isError`. Install/index/fixture/cache operations are issued exactly
once. Only completed Search reads may repeat if they finished before native
cancellation admission observation; those attempts are retained in the report.

Cancellation requires both the exact newly admitted running Editor operation and
its real native sidecar PID, read through an Observer-only private ownership seam.
After `notifications/cancelled`, the caller must receive no response, exact history
must say canceled without forced release, the own PID must be zero and the private
gate available. A separate Windows process-handle query must also confirm the
admitted PID physically exited; the diagnostic field alone is insufficient.
An independent follow-up Search must then succeed. The deterministic
100 ms gate deadline preserves the fixture's separate gate ownership and proves
that cancellation cleanup cannot release somebody else's semaphore lease.

Coverage: ready/idempotent install, bounded pages, four actual text→image matches,
GUID/local-file-ID/source-SHA metadata, uppercase/lowercase GUID canonicalization
and same-asset deduplication, cosine limit/filter, missing query/GUID,
malformed explicit refs/types/caps/unknown business and reserved-prefix fields
(isError, processed=0 and unchanged index SHA), real relay scope injection,
unavailable provider, changed/deleted source invalidation, same-GUID reindex,
same-path replacement GUID with deliberately current cached hashes/local ID,
deadline, native child cancellation, corrupt-cache clear, own cleanup and exact
scene/dirty preservation. All original saved author files are fully SHA-checked
once after cleanup. Optional `--author-baseline` uses a provided original root
baseline; otherwise the runner takes a fresh Assets/ProjectSettings SHA baseline
before creating fixtures. A provided reference is not claimed as a second fresh
full rehash.

The replacement test imports a new GUID only at the deleted own fixture path,
updates only the old owned cache row's hashes/local ID to make other identity
checks pass, and invokes the exact production native identity predicate against
that actual replacement object: new GUID accepts, old GUID rejects. Search must
then exclude the old entry. The report separately records whether this Editor
actually returned its cached stale old-GUID path; that path branch is claimed
only when observed. The replacement is SHA-guardedly deleted and the original
own PNG/meta restored before cleanup. Saved author assets are never replaced.

Portable command (paths supplied by the invoking workspace):

```
python -B run_native_visual_mcp.py --run --project <approved-Test-root> --relay <bundled-relay-executable> --smoke-module <run_mcp_smoke_regression.py> --validator-root <jsonschema-dependencies> --report <fresh-result.json>
```

The fixture/runner compile and syntax checks are candidate checks. Root must run
the actual live Mono/MCP gate and keep its full positive/negative evidence before
claiming frontend acceptance or publishing version 0.2.86.
