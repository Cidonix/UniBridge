# Serialized numeric precision

Run the published runner from an Administrator terminal with `--repo`, optional
`--candidate` mirrored repository root, `--newtonsoft`, `--unity-core` and a fresh
`--report`. It links the whole actual numeric helper, McpJson and Unity value
contracts; the named SerializedProperty adapter records which typed native
accessor the production helper selects. Expected literals test every numeric
width, UInt64 beyond Int64.MaxValue, exact Double values, range rejections before
setter admission and preserved ordinary Int32/Float conversions.

This managed gate is not native Editor proof. The opt-in Native/ gate uses
ordinary MCP Component writes and serialized reads, ScriptableObject MCP dry
run and the actual shared production writer over its owned asset. Independent
native CLR observations verify scalar, nested and array values and rejection
without mutation. It saves only the owned asset; the ScriptableObject MCP branch
that calls global SaveAssets is not executed against dirty authored assets.
See Native/README.md for the exact evidence and preservation boundaries.
Preserve authored assets/scenes and remove only owned fixture files after
identity/hash checks. The modern package uses
Unity's public numericType and signed/unsigned/double accessors. The separate
legacy adapter is unchanged and must be compiled/qualified with its own profiles.
