# Reflection path qualification

Run from an Administrator terminal. `Tools~` templates are not imported into host projects automatically.

The existing UnityValueRegression runner keeps its default math/schema suite; `--suite reflection` links this folder's focused tests, the whole actual resolver and the exact ManageGameObject conversion/read/compare bodies. Pass `--repo`, optional `--candidate`, `--newtonsoft`, `--unity-core`, and a fresh `--report`. Editor.CoreModule.dll is read beside the UnityEngine.CoreModule.dll SDK. This managed gate calls no Unity native material API; shader behavior requires the native gate below.

Native Mono gate (10 cases):

1. In the test project only, create a fresh UUID-owned folder under Assets; copy `ReflectionPropertyProbe.cs`, the shader, and the harness in an `Editor` subfolder. Generate a fresh shader .meta GUID, replace the harness marker `__OWNED_SHADER_GUID__` with that generated GUID, and preserve exact generated source/meta hashes. Refresh and wait for actual readiness/healthy compilation. Capture loaded scene handles, dirty flags, selection and authored-file hashes before import.
2. Snapshot Temp folders `unibridge-reflection-native-*`, call `UniBridge_ManageMenuItem` with Action=Execute and MenuPath=`Tools/UniBridge Qualification/Reflection Paths/Begin`, then require exactly one new UUID folder/native-report.json. Begin resolves only the owned shader through its GUID-backed typed Shader reference and creates its own unsaved additive DefaultGameObjects scene. No authored scene is saved or reloaded.
3. Run `run_native_reflection_probe.py --repo <repository> --project H:/Repos/UnityRepos/UniBridge_Test_Project --native-report <fresh-native-report> --report <fresh-external-report>`. It calls ordinary `UniBridge_ManageGameObject` once per payload, persists parsed MCP reply `raw` to each new wirePath, and calls Verify/Finish via the menu tool. It never replays an interrupted/unknown mutation. Expected negative `isError` and business failures are retained. A false physical or wire check fails qualification.
4. Cases cover nested property/field, list/array traversal, clamped physical actual mismatch, invalid index/null target rejection without mutation, actual Color/Vector shader endpoints and boolean-to-float normalization. The fixture checks independent physical state and verifies successful reports use the reflection route. Clamp must return false/readbackVerified=false with actualValue=1.
5. Driver always calls Finish once, even if a case fails. It checks owned root identities before closing only its own scene, destroys its own Material, restores original active scene and verifies author scene identities/loading/dirty flags. Its native-report.json is retained in the returned Temp UUID folder. A closed pass requires every case passed.
6. Remove only the unchanged UUID-owned fixture source/meta assets after their hashes still match, refresh and verify final readiness/compile health/console and original authored-file hashes. Preserve original dirty scene state; never save it for cleanup.

SDK compilation proves current 2020/2022/6.6 public APIs are compatible; full bridge SDK gates qualify integration separately. The standalone legacy adapter does not expose this ManageGameObject route; no native legacy reflection-route support is claimed here. CoreCLR is outside this gate.
